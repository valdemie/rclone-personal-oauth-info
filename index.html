Rclone Personal Backup

Esta es una aplicación OAuth de uso exclusivamente personal para realizar copias de seguridad mediante rclone.

La aplicación utiliza la API de Google Drive para acceder a los archivos de su propietario con permisos de solo lectura. Las copias se almacenan localmente y en Dropbox como almacenamiento de respaldo.

La aplicación no ofrece acceso a los archivos de Google Drive a otros usuarios y no constituye un servicio público.
